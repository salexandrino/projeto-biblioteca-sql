# Projeto Biblioteca SQL

Projeto de estudo feito para praticar SQL e MySQL.

## O que pratiquei

- Criação de banco de dados e tabelas
- Tipos de dados
- Chaves primárias e estrangeiras
- Restrições: NOT NULL, UNIQUE e DEFAULT
- Inserção e consulta de dados
- SELECT, WHERE, ORDER BY e JOIN

## Como executar

Abra o arquivo `biblioteca.sql` no MySQL Workbench e execute o script.
